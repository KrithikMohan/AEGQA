# AEQGA IBM hardware pilot implementation overlay

This is a source overlay for https://github.com/KrithikMohan/AEGQA.
Apply to a clean clone/branch: copy the supplied directories and files into
repository root, then run `python apply_hardware_integration.py` once.
See `docs/IBM_HARDWARE.md` for usage and limitations.

GitHub rejected automated branch creation with HTTP 403, so these files
are delivered separately and the remote repository was not changed.
